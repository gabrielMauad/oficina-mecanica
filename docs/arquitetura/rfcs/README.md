# RFCs — Request for Comments

Análise aberta das decisões técnicas relevantes do projeto: o problema, as alternativas
consideradas, os trade-offs de cada uma e a recomendação que saiu dali.

Onde a análise conclui em uma decisão permanente, ela é registrada numa ADR curta, que referencia o
RFC em vez de repetir o conteúdo. Ver [`../adrs/`](../adrs/).
